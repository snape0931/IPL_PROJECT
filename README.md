# 🏏 IPL Data Analysis

A **Python-based Exploratory Data Analysis (EDA)** project on IPL match data, focusing on team performance, toss decisions, match outcomes, and player statistics.

### 📊 Key Analysis

* Team-wise match wins
* Toss decisions & toss impact
* Match-winning methods
* Top Player of the Match performers
* Top run scorers
* Best bowling performances

### 🛠️ Tech Stack

**Python • Pandas • NumPy • Matplotlib • Seaborn • Jupyter Notebook**

### 📁 Project Files

* `IPL_PROJECT.ipynb` — Data analysis & visualizations
* `IPL.csv` — IPL dataset
